# Инструкция по созданию иконки приложения

## Использование изображения как иконки

Чтобы использовать ваше изображение как иконку приложения, выполните следующие шаги:

### Шаг 1: Сохраните изображение

1. Сохраните ваше изображение (описанное с гексагоном и волновой формой) в папку проекта
2. Рекомендуемые форматы: PNG, JPG, BMP
3. Рекомендуемое имя файла: `icon.png` или `icon.jpg`

### Шаг 2: Конвертация в ICO формат

Используйте созданный скрипт для конвертации изображения в ICO формат:

```bash
python create_icon_from_image.py icon.png app.ico
```

Где:
- `icon.png` - путь к вашему изображению
- `app.ico` - имя выходного файла (по умолчанию app.ico)

### Шаг 3: Проверка

После конвертации должен появиться файл `app.ico` в папке проекта.

### Шаг 4: Запуск приложения

При запуске приложения (`python main.py`) иконка будет автоматически загружена и отображена:
- В заголовке окна
- В панели задач
- В списке открытых приложений

## Альтернативный способ (ручная конвертация)

Если у вас возникли проблемы со скриптом, вы можете использовать онлайн-конвертеры:
1. https://convertio.co/png-ico/
2. https://www.icoconverter.com/
3. https://cloudconvert.com/png-to-ico

Рекомендуемые размеры для ICO файла:
- 256x256 пикселей (основной размер)
- Также хорошо иметь размеры: 128x128, 64x64, 48x48, 32x32, 16x16

## Требования

Для работы скрипта конвертации требуется:
- Python 3.11+
- Pillow (PIL) библиотека

Установка Pillow:
```bash
pip install Pillow>=10.0.0
```

## Проверка установки иконки

После создания `app.ico` и запуска приложения иконка должна отображаться:
- ✅ В заголовке окна приложения
- ✅ В панели задач Windows
- ✅ При создании EXE файла через PyInstaller

## Интеграция в PyInstaller

Для включения иконки в EXE файл, обновите файл `build_exe.bat` или добавьте параметр `--icon=app.ico`:

```batch
python -m PyInstaller --onefile --windowed --icon=app.ico main.py
```

Или обновите файл `PyQtApp.spec`:
```python
exe = EXE(
    ...
    icon='app.ico',
    ...
)
```
