Возможности

🚀

Параллельные запросы

Отправляйте промт в несколько моделей нейросетей одновременно для быстрого сравнения ответов.

💾

Сохранение результатов

Сохраняйте интересные ответы в базу данных с тегами для удобного поиска и организации.

📊

Экспорт данных

Экспортируйте результаты в форматы Markdown и JSON для дальнейшего анализа.

⚙️

Управление моделями

Легко добавляйте, редактируйте и настраивайте модели нейросетей через графический интерфейс.

🎨

Темная тема

Выбирайте между светлой и темной темой оформления для комфортной работы.

📝

Улучшение промптов

Используйте встроенную функцию улучшения промптов с помощью AI-ассистента.

Инструкция по установке

  1. Скачайте установщик
  2. Запустите Chatlist-Setup-X.X.X.exe
  3. Следуйте инструкциям мастера установки
  4. Запустите приложение из меню "Пуск"
  5. Настройте API-ключи в файле .env

Поддерживаемые модели
