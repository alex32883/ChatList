# Chatlist - Сравнение ответов нейросетей

Приложение для отправки одного промта в несколько нейросетей и сравнения их ответов.

## Возможности

- Отправка промта в несколько моделей одновременно
- Сохранение промтов с тегами
- Сохранение выбранных результатов в базу данных
- Экспорт результатов в Markdown и JSON
- Управление моделями через графический интерфейс
- Логирование всех запросов
- Поиск по сохраненным промтам

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в `.env`:
   ```bash
   copy .env.example .env
   ```

2. Откройте `.env` и добавьте ваши API-ключи:
   ```
   OPENROUTER_API_KEY=your_openrouter_api_key_here
   ```

## Запуск программы

```bash
python main.py
```

## Поддерживаемые модели

По умолчанию программа настроена на использование бесплатных моделей через OpenRouter:
- Llama 3.3 70B
- Mistral 7B
- OpenAI GPT-OSS
- Qwen3

Вы можете добавить свои модели через меню "Настройки" → "Управление моделями".

## Использование

1. Введите промт в текстовое поле
2. (Опционально) Добавьте теги через запятую
3. Нажмите "Отправить запрос"
4. Дождитесь получения ответов от всех моделей
5. Отметьте нужные результаты галочкой "Выбрать"
6. Нажмите "Сохранить" для сохранения в БД или "Экспорт" для экспорта в файл

## Структура проекта

- `main.py` - основной файл с GUI
- `db.py` - модуль для работы с базой данных SQLite
- `model.py` - логика работы с моделями
- `network.py` - отправка запросов к API
- `config.py` - загрузка конфигурации из .env
- `logger.py` - логирование запросов и ошибок
- `models_window.py` - окно управления моделями

## Логи

Логи сохраняются в папке `logs/` с именем файла по дате.

## Создание Windows исполняемого файла

Для создания исполняемого файла (.exe) используйте:

```bash
build_exe.bat
```

Или вручную:

```bash
pyinstaller --onefile --windowed --name "Chatlist" main.py
```

Исполняемый файл будет находиться в папке `dist`.
