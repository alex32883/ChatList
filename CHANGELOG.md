# Changelog

Все значительные изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2024-01-XX

### Добавлено
- Автоматическая сборка инсталлятора через GitHub Actions
- Поддержка версионирования через `version.py`
- HTML-лендинг для GitHub Pages
- Инструкция по публикации на GitHub Release

### Исправлено
- Исправлена проблема с запуском приложения после установки
- Улучшена сборка исполняемого файла с правильными зависимостями

## [1.0.0] - 2024-01-XX

### Добавлено
- Основной функционал приложения
- Отправка промтов в несколько моделей одновременно
- Сохранение промтов с тегами
- Сохранение выбранных результатов в базу данных
- Экспорт результатов в Markdown и JSON
- Управление моделями через графический интерфейс
- Логирование всех запросов
- Поиск по сохраненным промтам
- Улучшение промптов с помощью AI-ассистента
- Настройка темы оформления (светлая/темная)
- Настройка размера шрифта
- Инсталлятор для Windows (Inno Setup)
