# Исправление проблем с путями после установки

## Проблема

После установки приложения через инсталлятор могут возникать ошибки, связанные с неправильными путями к файлам:
- База данных не создается или не находится
- Логи не сохраняются
- Файл `.env` не находится
- Иконка не отображается

## Решение

Создан модуль `paths.py`, который правильно определяет пути к файлам для установленной и портативной версии приложения.

### Изменения

1. **Создан `paths.py`** - централизованное управление путями:
   - `get_app_dir()` - путь к папке приложения (где находится exe)
   - `get_user_data_dir()` - путь к папке пользовательских данных (`AppData\Local\Chatlist`)
   - `get_db_file()` - путь к базе данных
   - `get_log_dir()` - путь к папке с логами
   - `get_env_file()` - путь к .env файлу
   - `get_icon_path()` - путь к иконке

2. **Обновлены модули** для использования правильных путей:
   - `db.py` - использует `get_db_file()` из `paths.py`
   - `logger.py` - использует `get_log_dir()` из `paths.py`
   - `config.py` - использует `get_env_file()` из `paths.py`
   - `main.py` - использует `get_icon_path()` из `paths.py`

3. **Обновлен `PyQtApp.spec`**:
   - Добавлен `paths` в `hiddenimports`
   - Добавлена иконка в `datas`

4. **Обновлен `setup.iss`**:
   - Создает папку пользовательских данных при установке
   - Копирует `.env.example` в папку пользователя

## Расположение файлов

### После установки через инсталлятор:

**Папка установки** (`C:\Program Files\Chatlist\`):
- `PyQtApp.exe` - исполняемый файл
- `app.ico` - иконка приложения

**Папка пользовательских данных** (`C:\Users\USERNAME\AppData\Local\Chatlist\`):
- `chatlist.db` - база данных
- `.env` - файл с API-ключами (создается пользователем)
- `.env.example` - пример файла конфигурации
- `logs\` - папка с логами

## Что нужно сделать

### 1. Пересобрать приложение

```bash
# Пересобрать exe файл
python -m PyInstaller PyQtApp.spec --clean

# Пересобрать инсталлятор
build_installer.bat
```

### 2. Протестировать установку

1. Установите приложение на чистой системе (или удалите старую версию)
2. Запустите приложение
3. Проверьте, что создается база данных в `AppData\Local\Chatlist\`
4. Проверьте, что создается папка `logs\`
5. Создайте файл `.env` в `AppData\Local\Chatlist\` с вашими API-ключами

### 3. Настройка .env файла

После установки создайте файл `.env` в папке:
`C:\Users\YOUR_USERNAME\AppData\Local\Chatlist\.env`

Содержимое:
```
OPENROUTER_API_KEY=your_api_key_here
```

## Проверка работы

После запуска приложения проверьте:

1. **База данных**: `C:\Users\YOUR_USERNAME\AppData\Local\Chatlist\chatlist.db` должна создаться
2. **Логи**: `C:\Users\YOUR_USERNAME\AppData\Local\Chatlist\logs\` должна создаться
3. **Иконка**: должна отображаться в окне приложения
4. **Настройки**: должны сохраняться в базе данных

## Если проблемы остались

1. Проверьте права доступа к папке `AppData\Local\Chatlist\`
2. Проверьте, что файл `paths.py` включен в сборку
3. Включите отладочный режим (console=True в PyQtApp.spec) для просмотра ошибок
4. Проверьте логи в `AppData\Local\Chatlist\logs\`

## Откат изменений

Если нужно вернуться к старым путям (не рекомендуется):

1. Замените `DB_FILE = "chatlist.db"` в `db.py`
2. Замените `LOG_DIR = "logs"` в `logger.py`
3. Используйте относительные пути в `config.py` и `main.py`

Но учтите, что это может вызвать проблемы с правами доступа в папке установки.
