# Инструкция по созданию инсталлятора

## Требования

1. **Inno Setup 6** - скачать можно с [официального сайта](https://jrsoftware.org/isdl.php)
2. **Python** - для автоматического получения версии из `version.py`

## Создание инсталлятора

### Автоматический способ (рекомендуется)

Запустите `build_installer.bat` - скрипт автоматически:
- Получит версию из `version.py`
- Обновит `setup.iss` с правильной версией
- Скомпилирует инсталлятор

```batch
build_installer.bat
```

Инсталлятор будет создан в папке `installer` с именем `Chatlist-Setup-{версия}.exe`

### Ручной способ

1. Откройте `setup.iss` в Inno Setup Compiler
2. Убедитесь, что версия в строке `#define AppVersion` соответствует версии в `version.py`
3. Нажмите "Build" → "Compile" (или F9)

## Особенности инсталлятора

### Установка
- Устанавливает приложение в `Program Files\Chatlist`
- Создает ярлыки в меню "Пуск"
- Опционально создает ярлык на рабочем столе
- Добавляет записи в реестр Windows

### Деинсталляция
Инсталлятор включает полную секцию деинсталляции, которая:
- Удаляет все файлы приложения из папки установки
- Удаляет базу данных `chatlist.db` (если она находится в папке установки)
- Удаляет папку с логами `logs`
- Удаляет записи из реестра Windows
- Удаляет ярлыки из меню "Пуск" и с рабочего стола

### Примечания
- База данных и логи создаются в папке, где запускается приложение
- При деинсталляции все пользовательские данные (БД, логи) будут удалены
- Если нужно сохранить данные, скопируйте их перед деинсталляцией

## Структура файлов

- `setup.iss` - основной скрипт Inno Setup
- `build_installer.bat` - скрипт для автоматической сборки
- `version.py` - файл с версией приложения
- `dist\PyQtApp.exe` или `dist\PyQtApp-{версия}.exe` - исполняемый файл для установки
- `app.ico` - иконка приложения (опционально)

## Настройка пути к Inno Setup

Если Inno Setup установлен в нестандартное место, отредактируйте `build_installer.bat` и укажите правильный путь:

```batch
set INNO_SETUP="C:\Your\Path\To\Inno Setup 6\ISCC.exe"
```
